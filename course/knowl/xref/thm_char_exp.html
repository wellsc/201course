Theorem 18 Characterization of Exponential Functions.

For any function \(f\text{,}\) if
  1. \(f\) is continuous for all real numbers \(x\text{,}\)
    🔗
    🔗
  2. \(f(0)=1\text{,}\)
    🔗
    🔗
  3. there is a positive real number \(r\) so that \(f(1)=r\text{,}\) and
    🔗
    🔗
  4. for all real \(a\) and \(b\text{,}\) \(f(a)\cdot{}f(b)=f(a+b)\text{,}\)
    🔗
    🔗
then for any real \(x\text{,}\) \(f(x)=r^{x}\text{.}\)
