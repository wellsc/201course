Example 41.

Let \(f(x)=4\text{.}\) That is, no matter what value of \(x\)we input into \(f(x)\text{,}\) the output will be \(4\text{.}\) Then the derivative of \(f(x)\) is given by
\begin{align*} f'(x)&=\lim_{u\to{}x}\frac{f(u)-f(x)}{u-x}\\ &=\lim_{u\to{}x}\frac{4-4}{u-x}\\ &=\lim_{u\to{}x}\frac{0}{u-x}. \end{align*}
For every value of \(u\neq{}x\text{,}\) \(\frac{0}{u-x}=0\text{.}\)
 2 
One way to think about this is that in the limit \(\lim_{u\to{}x}\frac{0}{u-x}\text{,}\) the numerator is \(0\text{,}\) while the denominator is approaching \(0\text{.}\)
This means that the expression \(\frac{0}{u-x}\) is identical with \(0\) except when \(u=x\text{.}\) Thus,
\begin{align*} f'(x)&=\lim_{u\to{}x}\frac{f(u)-f(x)}{u-x}\\ &=\lim_{u\to{}x}\frac{0}{u-x}\\ &=\lim_{u\to{}x}0\\ &=0. \end{align*}
